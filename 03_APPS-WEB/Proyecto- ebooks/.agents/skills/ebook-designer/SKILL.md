# Ebook Designer Skill

Esta Skill es responsable de la estética editorial premium, la maquetación visual y la compilación técnica en formatos descargables e imprimibles.

## Responsabilidades
1. **Sistema Visual y Paleta Cromática:**
   - Color Primario (Fondo / Dark mode / Títulos): Azul marino oscuro / Medianoche (`#0F172A` / `#1E293B`).
   - Color Acento Primario: Azul eléctrico tecnológico (`#2563EB` / `#3B82F6`).
   - Color Acento Secundario: Violeta sofisticado (`#7C3AED` / `#8B5CF6`).
   - Neutros de Fondo: Blanco puro (`#FFFFFF`) y Gris tenue de lectura (`#F8FAFC`).
   - Texto de Párrafo: Gris carbón de alta legibilidad (`#334155`).
2. **Jerarquía Tipográfica:**
   - Títulos Principales: Sans-serif moderna, geométrica o humanist (Inter, Helvetica Neue, Calibri / Arial).
   - Cuerpo de texto: Escala tipográfica equilibrada con interlineado generoso (1.4 - 1.6) para evitar fatiga visual.
3. **Componentes Visuales Editorializados:**
   - Recuadros de Evidencia Científica (borde azul, fondo azul tenue, icono de microscopio/laboratorio).
   - Recuadros de Advertencia / Trampas cognitivas (borde ámbar/rojo, icono de alerta).
   - Cajas de Prompts Listos para Copiar (fondo gris oscuro o monospace con botón visual de copia).
   - Fichas de Ejercicio y Plantillas de aplicación directa.
4. **Exportación Técnica:**
   - Generación de manuscrito formateado en DOCX con estilos tipográficos estándar.
   - Generación de PDF diagramado con numeración, saltos de página inteligentes, encabezados y pie de página.
