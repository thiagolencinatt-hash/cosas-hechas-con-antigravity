# Project Manager Skill

Esta Skill coordina integralmente la factoría de producción de ebooks, supervisando que cada fase se ejecute con estándares de rigor, puntualidad y completitud.

## Responsabilidades
1. **Gobierno de Etapas (Pipeline):**
   - **ETAPA 1:** Inspección de entorno y organización de carpetas.
   - **ETAPA 2:** Creación y verificación de Agent Skills y AGENTS.md.
   - **ETAPA 3:** Lectura y auditoría científica del documento de investigación.
   - **ETAPA 4:** Matriz de trazabilidad (Fuentes <-> Capítulos).
   - **ETAPA 5:** Redacción íntegra de los 7 capítulos (13 secciones obligatorias c/u).
   - **ETAPA 6:** Desarrollo del kit descargable (10 plantillas funcionales).
   - **ETAPA 7:** Auditoría de fact-checking y control de calidad.
   - **ETAPA 8:** Diseño editorial y estandarización visual.
   - **ETAPA 9:** Compilación técnica de entregables (DOCX, PDF, Markdown).
   - **ETAPA 10:** Generación de dossier comercial y reporte final de calidad.
2. **Gestión de Memoria y Estado:**
   - Mantener actualizados `00_ESTADO/CURRENT_STATE.md` y `00_ESTADO/TASKS.md`.
   - Evitar tareas duplicadas o abandonadas a mitad de camino.
   - Garantizar que ningún entregable sea ficticio o incompleto.
