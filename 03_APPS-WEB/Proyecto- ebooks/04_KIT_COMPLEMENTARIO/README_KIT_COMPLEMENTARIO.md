# KIT COMPLEMENTARIO DE APRENDIZAJE ACELERADO CON IA
## Guía de Recursos, Plantillas y Biblioteca de Prompts

Bienvenido al kit de herramientas prácticas descargables que acompaña al libro **"El Sistema de Aprendizaje Acelerado con IA: Cómo Dominar Cualquier Tema en Tiempo Récord"**.

Este kit fue diseñado bajo el principio de **utilidad funcional inmediata**: cada documento es una plantilla imprimible o rellenable, una matriz de análisis o un banco de instrucciones optimizadas para interactuar con modelos de inteligencia artificial (ChatGPT, Gemini, NotebookLM).

## Cómo Utilizar este Kit
1. **No intentes llenar todo el primer día:** Cada recurso corresponde a una fase y a un capítulo específico del libro.
2. **Imprimí o completá digitalmente:** Los archivos están formateados en Markdown estándar para que puedas editarlos directamente en tu editor favorito, en Notion o imprimirlos en papel.
3. **Mantené tu carpeta a mano:** Cuando interactúes con tu IA, tené abierta la Biblioteca de Prompts (`05`) y la plantilla de registro correspondiente.
