# 🚀 Cosas hechas con Antigravity

Repositorio de proyectos creados con la ayuda de Antigravity AI.  
Organizado en 4 grupos temáticos para facilitar la navegación.

---

## 📁 Estructura

```
cosas hechas con antigravity/
│
├── 01_FACULTAD/                        ← Proyectos académicos
│   ├── apuntes-facultad/               Python watcher + Google Drive para apuntes
│   └── reforma-climatologia/           Apuntes de climatología (reforma)
│
├── 02_HERRAMIENTAS-ANTIGRAVITY/        ← Tools para la plataforma Antigravity
│   ├── pasar-cuenta-completo/          Sistema completo de transferencia de sesión
│   ├── pasar-cuentas/                  Herramienta para cambiar cuentas
│   └── notebooklm-prompts/             Prompts y guías para NotebookLM
│
├── 03_APPS-WEB/                        ← Aplicaciones web y frontend
│   ├── fotos-app-ia/                   App Vite+React+TS para fotos con IA
│   ├── donas-prototipo/                App de donuts (Next.js)
│   └── trucogame/                      Juego de Truco (Vite/JS + extensión Chrome)
│
└── 04_CREATIVOS-Y-MEDIA/              ← Proyectos creativos, bocetos y media
    └── fotos-ia/                       Fotos y bocetos generados con IA
```
